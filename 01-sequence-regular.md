# Диаграмма последовательности № 1: приём и обработка кадра

Показывает обычный сценарий с обработкой без очереди и с ожиданием в буфере. Здесь выбор сервера зависит от приоритета номера (Д2П1), а выбор ожидающего снимка — от LIFO (Д2Б2).

```mermaid
sequenceDiagram
    autonumber
    actor Camera as Камера парковки
    participant Receive as Модуль приёма кадров
    participant Dispatch as Диспетчер
    participant Buffer as Буфер снимков
    participant Server as Сервер распознавания
    participant Board as Информационное табло

    Camera->>Receive: Передать кадр (cameraId, frameId, time, image)
    Receive->>Dispatch: Новая заявка на анализ
    alt Есть свободный сервер
        Note over Dispatch,Server: Выбор сервера по приоритету номера (Д2П1)
        Dispatch->>Server: Передать кадр
    else Все серверы заняты, буфер не полон
        Dispatch->>Buffer: Добавить кадр в конец (Д10З2)
        Note over Buffer,Server: Ожидание завершения обработки одного из кадров
        Server-->>Dispatch: Сервер освободился
        Dispatch->>Buffer: Взять самый новый ожидающий кадр (LIFO, Д2Б2)
        Buffer-->>Dispatch: Кадр на обслуживание
        Dispatch->>Server: Передать выбранный кадр
    end
    Server->>Server: Распознать автомобили и свободные места (ПЗ2)
    Server-->>Board: Передать число свободных мест
```

**Связь с бизнес-доменом:** источником выступает камера; заявка — снимок; прибор — сервер распознавания; выход — сведения для табло. Время анализа имеет равномерное распределение (ПЗ2) в имитационной модели.
